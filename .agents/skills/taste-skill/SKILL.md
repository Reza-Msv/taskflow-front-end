# Taste & Visual Polish Skill

## Rules

1. **Restrained Color Palettes**: Use purposeful semantic colors. Avoid decorative random gradients or candy-colored charts.
2. **Spacing & Rhythm**: Consistently adhere to 4px/8px grid increments (`gap-2`, `gap-4`, `p-6`).
3. **Typography**: Establish clear hierarchy using font weights and muted subheadings rather than extreme size jumps.
4. **Micro-Interactions**: Use smooth, subtle transitions (`transition-colors duration-150`). Avoid jarring bounce animations.
