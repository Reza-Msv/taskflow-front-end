# UI/UX Enterprise Pro Skill

## Rules

1. **Operational Density**: Desktop interfaces must support compact views for scanning dozens of issues and board cards efficiently.
2. **Form Usability**:
   - Provide immediate inline validation with Zod.
   - Disable submit buttons while requests are pending to prevent duplicate submissions.
3. **Empty States**: Never show a blank screen. Provide an illustration or icon, an explanation, and a primary CTA (e.g. "Create your first task").
4. **Error Recovery**: Display actionable error alerts with a "Retry" button.
