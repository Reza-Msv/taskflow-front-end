# Frontend Performance Skill

## Rules

1. **Dynamic Imports**: Lazy-load heavy dialogs and chart libraries with `next/dynamic`.
2. **TanStack Query Caching**: Configure sensible `staleTime` and deduplicate identical inflight network requests.
3. **Optimized Layouts**: Avoid layout shifts (CLS) by giving images and loading cards explicit aspect ratios and skeleton dimensions.
