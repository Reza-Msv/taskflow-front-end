# Accessibility Skill

## Rules

1. **Keyboard First**: Every button, card, modal, and dropdown must be operable via keyboard (`Tab`, `Enter`, `Space`, `Escape`).
2. **Accessible Names**: All icon-only buttons must have `aria-label` or visually hidden screen reader text.
3. **Contrast**: Text contrast must meet 4.5:1 ratio against backgrounds in both light and dark modes.
4. **RTL Support**: Use logical CSS properties (`ms-*`, `me-*`, `start-*`, `end-*`) to support both LTR and RTL layouts.
