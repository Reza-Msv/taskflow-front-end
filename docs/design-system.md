# Design System & UI Tokens

## Colors

TaskFlow uses a refined Slate/Blue palette:

- **Background**: Pure white `#ffffff` (light) / Dark Slate `#020817` (dark)
- **Primary**: Indigo/Blue `#2563eb` (light) / `#3b82f6` (dark)
- **Muted**: Soft Gray for secondary captions and background fills.

## Density Standards

- Table row height: `h-10` to `h-12` for compact review.
- Board cards: Structured metadata badges (priority, assignee avatar, issue key `WEB-12`).
- Responsive: Fluid layout scaling down to mobile viewports with toggleable sidebar navigation.
